# Mindset idea bank

Starting points for the **Mindset posts (cloud)** routine. Use an unused one (check `history.json`) or write a new one in the same spirit: one contrast, builder mindset, tied to "Stop guessing what to build." No digits. Never reuse the reference creator's concepts or lines (see `reference/STYLE.md`).

## Reels (left lane · right lane · object · punchline idea)
- guesser (builds first, restart) · solver (asks first, steady) · bricks · Same effort, a real problem underneath.
- idea collector (saves ideas, idle) · problem hunter (talks to users, steady) · stairs · Notes don't climb. Conversations do.
- stealth mode (builds alone, burst) · in the open (shows early, steady) · bricks · Feedback is cheaper before the wall is up.
- waiting (for the perfect idea, idle) · starting (with a small problem, steady) · stairs · Small problems are still steps.
- feature hoarder (adds more, restart) · problem fixer (fixes one, steady) · bricks · One fixed pain beats ten features.
- trend chaser (switches weekly, restart) · problem keeper (stays put, steady) · stairs · Switching resets the climb.
- overthinker (plans more, stall) · tester (tries small, steady) · bricks · A small test answers what a plan can't.
- copier (clones an app, burst) · researcher (reads the pain, late) · stairs · Starting late on the right problem still wins.
- solo genius (no users, restart) · listener (asks users, steady) · bricks · Users are the blueprint.
- tutorial loop (learns forever, idle) · project builder (learns by solving, steady) · stairs · Skills stick when they solve something.
- hackathon idea (fun, burst) · career project (real pain, steady) · bricks · A real problem is a better portfolio.
- pitch first (deck, stall) · proof first (evidence, steady) · stairs · Evidence carries the pitch.
- loud launch (hype, burst) · quiet fix (one user, steady) · bricks · Hype fades. Solved problems stay.
- blank page (no direction, idle) · case file (clear problem, steady) · stairs · Direction beats motivation.
- guessing price (no buyer, restart) · knowing buyer (who pays, steady) · bricks · Know who pays before you build.
